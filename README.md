# DICE

面向《克苏鲁的呼唤》第七版（Call of Cthulhu 7th Edition）的轻量网页骰子终端。

DICE 是聊天平台上的骰子机器人无法使用时的备用方案：打开网页即可掷骰、判定、管理调查员，无需服务器、账号或安装。主要面向 KP，也可以由整桌玩家共同使用。

本项目仅适配 CoC 七版，不包含调查员创建流程。

## 特性

- **指令终端**：支持 `.r`、`.ra`、`.sc`、`.st` 等常用指令，同时提供按钮面板
- **七版判定**：成功等级、奖励骰 / 惩罚骰、理智检定、技能成长
- **多调查员**：同一局内管理多个 PC，随时切换，各自数据独立
- **随机属性**：按七版规则生成调查员属性，输出可直接复制
- **历史总结**：按调查员分组的属性摘要、判定统计与完整记录
- **纯前端**：单个 HTML 文件，数据保存在浏览器本地，无需后端

## 使用流程

以「一个模组一份数据」为单位使用：

1. **开团前**：用 `.st` 导入调查员，或在 INVESTIGATORS 页新建、编辑。
2. **游戏中**：在 TERMINAL 页掷骰。技能检定成功时，该技能自动标记为可成长。
3. **模组结束**：在 GROWTH 页结算成长骰。
4. **下一个模组**：在 HISTORY 页点击「清空历史」。这会清除全部历史记录和未结算的成长标记；调查员数据保留，可继续使用或自行修改。

## 页面

| 页面 | 说明 |
| --- | --- |
| HOME | 入口 |
| TERMINAL | 指令输入与按钮面板：骰子、检定（含奖励 / 惩罚骰模式）、理智检定、HP / MP / SAN 状态调整 |
| ROLL | 随机生成七版调查员属性，可复制或采用为调查员 |
| INVESTIGATORS | 调查员管理：属性、状态、技能、`.st` 导入与导出、复制与删除 |
| HISTORY | 按调查员分段的总结：属性摘要、成功等级统计、状态变化、全部记录 |
| GROWTH | 跑团结束后的成长骰结算 |

## 指令

| 指令 | 说明 |
| --- | --- |
| `.r [NdM±K]` | 通用骰，默认 `1d100`（1–100 个骰，2–1000 面） |
| `.ra 技能 [目标值]` | 技能 / 属性判定；省略目标值时读取当前调查员数据 |
| `.ra b\|p[1-3] 技能` | 带奖励骰（`b`）或惩罚骰（`p`）的判定，数字为额外十位骰数量，如 `.ra b2 聆听` |
| `.rb` `.rp [数量] [技能或目标值]` | 同上；不带技能时为单纯的 D100 |
| `.sc 成功损失/失败损失` | 理智检定，如 `.sc 1/1d6` |
| `.st 属性技能…` | 导入属性与技能，如 `.st 力量75敏捷60意志70聆听40侦查75`；无当前调查员时自动新建 |
| `.hp` `.mp` `.san` `[+n\|-n\|n]` | 查看或修改；`+n` / `-n` 增减，`n` 直接设置，输出前后数值 |
| `.coc [1–10]` `.coc7` | 随机生成属性；一次可生成多组供选择，不会覆盖已有调查员 |
| `.name 名字` | 设置人物作成中显示的名字 |
| `.pc [序号或名字]` | 列出或切换调查员 |
| `.growth` | 结算当前调查员已标记技能的成长骰 |
| `.en 技能…` | 对指定技能进行成长检定 |
| `.help` | 指令说明 |

`.st` 支持中文属性名、英文缩写（`str`、`dex`、`pow` 等）以及中英混合输入。遇到重复字段、无法识别的内容会给出提示；无法识别的名称会作为自定义技能导入。

## 规则

### 成功等级

| 骰点 | 结果 |
| --- | --- |
| 1–5 | 大成功 |
| ≤ 目标值 ÷ 5 | 极难成功 |
| ≤ 目标值 ÷ 2 | 困难成功 |
| ≤ 目标值 | 普通成功 |
| > 目标值 | 失败 |
| 95–100 | 大失败 |

- 大成功、大失败的区间固定为 1–5 与 95–100，不随目标值变化，并优先于其他等级判定。
- 极难、困难的临界值向下取整。

### 奖励骰与惩罚骰

在原 D100 之外额外掷 N 个十位骰（N = 1–3），每个十位骰分别与同一个个位骰组合成结果：

- **奖励骰**：取最低结果
- **惩罚骰**：取最高结果

个位为 0 时，十位 00 记作 100。

### 理智检定

`.sc 成功损失/失败损失`：对当前 SAN 掷 D100。判定成功扣除「成功损失」，失败扣除「失败损失」；大失败时失败损失取最大值。输出 SAN 变化前后的数值。

### 成长骰

- 技能检定成功（含大成功）时，该技能自动标记，同一技能每个模组只记一次。使用手动目标值的检定、属性检定、SAN 检定以及克苏鲁神话不会标记。
- 结算时对每个已标记技能掷 D100：结果大于当前技能值，或大于 95，则技能增加 1D10（上限 99）。
- 技能因此升到 90 以上时，SAN 恢复 2D6（上限 99）。
- 结算后标记清空。也可在 GROWTH 页手动增减标记。

### 随机属性（`.coc`）

| 项目 | 公式 |
| --- | --- |
| 力量、体质、敏捷、外貌、意志、幸运 | 3D6 × 5 |
| 体型、智力、教育 | (2D6 + 6) × 5 |
| HP | (体质 + 体型) ÷ 10，向下取整 |
| MP | 意志 ÷ 5 |
| SAN | 意志 |
| DB | 按力量 + 体型：< 65 为 −2；65–84 为 −1；85–124 为 0；125–164 为 1D4；165–204 为 1D6 |

输出格式：

```
调查员的七版COC人物作成:
力量:75 敏捷:35 意志:65
体质:55 外貌:50 教育:45
体型:60 智力:70 幸运:55
HP:11 <DB:1d4> [455/510]
```

`[ ]` 中依次为不含幸运与含幸运的属性总和。

## 数据

- 所有数据保存在浏览器的 `localStorage`（键名 `dice.v1`），不会上传到任何服务器。
- 历史记录最多保留 500 条。
- 清除浏览器站点数据会同时清除调查员与历史。需要迁移调查员时，可在 INVESTIGATORS 页的「导入」标签导出 `.st` 文本，在新设备上导入。

## 技术说明

- 原生 HTML / CSS / JavaScript，单文件，无构建步骤，无第三方脚本依赖。
- 需要支持 CSS 容器查询的现代浏览器（Chrome / Edge 105+、Safari 16+、Firefox 110+）。字体通过 Google Fonts 加载，离线时回退为系统字体，不影响功能。
- 核心骰子逻辑不依赖任何外部服务；外部请求仅用于加载 Google Fonts。
- 成功等级的判定位于脚本中的 `judge()` 函数；如需调整大成功 / 大失败区间，修改该函数即可。
